# This project uses two synthetic CSV datasets:

# 1.GeoPluse_store_location.csv
Contains information about three store locations, including two existing stores and one proposed candidate location.
## Columns:
##  store_id
##  store_name
##  store_status
##  latitude
##  longitude
##  catchment_radius_m

# 2.GeoPluse_500_synthetic_GPS_Pings.csv
Contains 500 anonymized synthetic GPS records representing movement across different geographical areas.

# Columns:
## ping_id
## device_id
## latitude
## longitude
## timestamp
## activity_area
## day_of_week
## hour
## daypart
## movement_mode
## gps_accuracy_m
## is_anonymized
## nearest_store_distance_m
## within_500m_of_nearest_store
