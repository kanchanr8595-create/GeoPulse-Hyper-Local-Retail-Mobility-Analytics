
# GeoPulse Dataset

## Purposes
This folder stores the synthetic GPS movement dataset used in the GeoPulse project.

## Expected Data
- Device or vehicle identifiers
- GPS latitude and longitude
- Timestamp
- Movement speed
- Heading or direction
- Movement status

## Data Source
Synthetic GPS data generated by the project team.
