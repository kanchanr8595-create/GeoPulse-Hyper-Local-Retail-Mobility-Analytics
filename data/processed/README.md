
# Processed Data

This folder stores processed outputs generated
during the GeoPulse GPS Analytics project.

Original raw datasets must remain unchanged.

---

## Day 1 – Project Setup
- Prepared project folder structure.
- Defined the data storage approach.
- Identified raw and processed data requirements.

## Day 2 – GPS Data Understanding
- Reviewed GPS dataset structure.
- Identified important GPS attributes.
- Understood latitude, longitude and timestamp fields.

## Day 3 – GPS Movement Logic
- Prepared GPS coordinate validation logic.
- Added Haversine distance calculation.
- Developed next-position calculation logic.
- Added movement logic test cases.

## Day 4 – GPS Data Integration
- Integrated GPS ping and store location datasets.
- Prepared data loading and inspection logic.
- Documented GPS dataset integration.

## Day 5 – GPS Movement Analysis
- Prepared device-wise GPS movement analysis.
- Worked on distance and time-based movement calculations.
- Prepared device movement summary logic.
- Documented GPS movement analysis.

## Day 6 – Store Proximity Analysis
- Identified the nearest store for each GPS ping.
- Calculated distance between GPS pings and stores.
- Compared distance with store catchment radius.
- Prepared store-wise activity summary.

### Expected Output Files
- store_proximity_analysis.csv
- store_activity_summary.csv
