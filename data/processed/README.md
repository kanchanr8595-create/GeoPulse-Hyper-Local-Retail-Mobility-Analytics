## Day 6 – Store Proximity Analysis

This folder stores processed outputs generated
from GPS and store location analysis.

### Expected Output Files

1. store_proximity_analysis.csv
   - Nearest store for each GPS ping
   - Distance from the nearest store
   - Catchment radius comparison

2. store_activity_summary.csv
   - Store-wise GPS ping count
   - Pings within and outside catchment
   - Average distance from store

These files are generated by Python analysis scripts.
