
# Time-Based GPS Activity Analysis

## Objective
To understand how GPS activity varies across
different hours and dayparts.

## Input Dataset
GeoPulse_500_Synthetic_GPS_Pings.csv

## Analysis Performed
1. Loaded the GPS ping dataset.
2. Used hour and daypart columns.
3. Grouped GPS pings by daypart.
4. Grouped GPS pings by hour.
5. Calculated total GPS pings for each time period.

## Output
time_based_activity_summary.csv

## Business Benefits
- Understand time-based movement patterns.
- Identify periods with higher GPS activity.
- Support location and operational planning.

## Limitation
GPS activity does not directly represent
customer footfall or sales.
