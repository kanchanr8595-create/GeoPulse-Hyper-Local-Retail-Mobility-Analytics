
# GeoPulse Dashboard Layout Plan

## Dashboard Title
GeoPulse - GPS Movement & Store Activity Dashboard

## Section 1 - KPI Cards
- Total GPS Pings
- Unique Devices
- Average GPS Accuracy
- Catchment Pings
- Catchment Coverage %

## Section 2 - GPS Activity Trends
Visualizations:
- Hour-wise GPS activity
- Daypart-wise GPS activity
- Day-of-week activity

Purpose:
Identify time-based movement patterns.

## Section 3 - Movement Analysis
Visualizations:
- Movement mode distribution
- GPS activity by area
- Device movement summary

Purpose:
Understand movement patterns and location behaviour.

## Section 4 - Store Analysis
Visualizations:
- GPS pings by store
- Average distance from store
- Catchment comparison

Purpose:
Compare GPS activity around different store locations.

## Section 5 - Filters / Slicers
- Day of week
- Daypart
- Movement mode
- Activity area
- Store

## Dashboard Design Guidelines
- Use a clean 16:9 layout.
- Use consistent colors and fonts.
- Keep KPI cards at the top.
- Use readable chart titles and labels.
- Avoid unnecessary visual clutter.
- Keep slicers grouped together.

## Data Limitation
GPS activity is not equivalent to actual customer
footfall, store visits or sales.
