# GeoPulse – Day 1 Visualization Research

## Objective
Research Kepler.gl and understand how it can be used for GeoPulse retail mobility analytics.

## 1. What is Kepler.gl?
Kepler.gl is an open-source geospatial visualization tool used to display and analyze location-based data on interactive maps.

## 2. Use in GeoPulse
Kepler.gl will help visualize:
- GPS location points.
- Retail store locations.
- Customer movement patterns.
- Store catchment areas.
- Morning and evening footfall.

## 3. Required Map Layers
1. Point Layer – Displays GPS locations.
2. Hexagon Layer – Displays geographical activity density.
3. Arc Layer – Shows movement between locations.
4. Polygon Layer – Displays store catchment areas.

## 4. Required Data Fields
- DeviceID
- Latitude
- Longitude
- Timestamp
- StoreID

## 5. Expected Outcome
Understand Kepler.gl features and identify suitable map visualizations for the GeoPulse project.

## 6. Conclusion
Kepler.gl can help GeoPulse present geographical movement and retail footfall patterns through interactive maps.
