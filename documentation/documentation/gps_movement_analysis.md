# GPS Movement Analysis

## Objective
To analyze GPS movement for individual devices.

## Analysis Steps
1. Sort GPS records by device and timestamp.
2. Identify previous GPS coordinates.
3. Calculate distance between consecutive pings.
4. Calculate time difference.
5. Estimate device movement speed.
6. Prepare device-wise movement summary.

## Expected Outputs
- Distance between consecutive GPS pings
- Time difference between observations
- Estimated movement speed
- Device-wise movement summary
